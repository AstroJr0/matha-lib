## Philosophy
well simply, its hard to make own `functions` or defining `constants` again and again from scratch just for one single value check. why not have various useful ones built in?

## Usage

```python
import matha
```

Or maybe this:
```python
import matha as mace
```

>[!TIP]
> `mace` *stands for **M**atha is now **A** **C**-**E**xtention*
